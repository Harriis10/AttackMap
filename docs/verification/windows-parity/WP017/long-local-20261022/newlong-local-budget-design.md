## Smallest change and dependency chain

Do not introduce another deadline, reset per jury vote, increase token/call/jury limits, change modes, or raise default values. Keep the individual OpenAI SDK request ceiling at 3600.

Current path is QA arguments -> `ParitySmokeTimeouts` -> `MainWindow.ParitySmoke.cs` -> `ProviderConfiguration` / `ProviderSettingsView` -> serialized native request -> Python `ProviderOptions` -> `desktop_worker.py:213` constructs one `AiBudget(max_seconds=provider.timeout_seconds)` -> shared Hunt/jury execution -> `llm_review._openai_timeout_ceiling` and reservation/remaining-time clamps. The existing Python SDK test already covers a 7200-second ledger producing a 3600-second individual request. Therefore increasing the SDK constant or altering `AiBudget`/jury orchestration is unnecessary.
